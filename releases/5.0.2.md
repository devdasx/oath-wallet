# Oath Wallet 5.0.2 (104) — prerelease

This GitHub prerelease collects the public audit repairs merged after 5.0.1
(103). It has not been uploaded or submitted to App Store Connect. The separate
5.0.1 submission is unchanged.

## Changes

- Correct interrupted wallet-import recovery, wallet-family counters, ordering
  bounds and Bitcoin address discovery/recovery journals.
- Make encrypted backup file reads and publication resilient to file races;
  reject stale progress callbacks after cancellation or a newer backup run.
- Clear revealed private-key content when leaving the foreground.
- Reject malformed WalletConnect key, address, signature and ENS encodings.
- Correct XRP issued-token arithmetic and reject inconsistent simulation replies.
- Prevent wallet removal from losing pending dApp recovery journals, including
  concurrent signing/journaling and interrupted encrypted persistence.

## Verification and audit scope

The [security-review repository](https://github.com/devdasx/oath-wallet-security-review)
tracks this prerelease as its current target. Historical before/after experiments
retain their exact source pins; they are not relabelled as tests of build 104.
The attached verification record contains checks performed on this release's
exact source. Source review and passing tests do not establish zero bugs,
independent certification or equivalence with Apple's distributed binary.

The whole-wallet review remains in progress. No simulator, physical device or
App Store operation is part of preparing this prerelease.
