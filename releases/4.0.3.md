# Oath Wallet 4.0.3

Version **4.0.3**, build **77**.

This release brings the new Oath app to the public source repository, replacing
the previous app layout while preserving the repository's release history.

## App updates

- Redesigned native screens, refreshed branding, and selectable app icons.
- Updated send and receive flows, QR scanning, and transaction details.
- Multichain asset discovery with token logos, pricing, and history.
- Clearer WalletConnect request review and network-aware signing integrations.
- Permissions grouped by network, with selection and batch revocation.
- Improved wallet switching, Recently Deleted, authentication, and legacy-wallet
  upgrade handling.
- Refresh, scrolling, and layout refinements across the app.

Availability depends on the network, token, provider configuration, and device.
This release does not claim every dApp, chain, or transaction path was tested.

## Public source package

The release includes app source, assets, local Swift packages, the patched Reown
source, and tests. Private backend code, recovery-upload integration, remote
diagnostics transport, API keys, signing credentials, and local configuration
are excluded. Diagnostics remain privacy-filtered and local in this source build.
Wallet key storage and transaction signing remain on-device.

To build, run `sh Tools/PreparePublicBuild.sh` and open
`OathAtmosphere.xcodeproj`. Select the `OathAtmosphere` scheme. The script creates
only an empty ignored provider configuration; add your own configuration for
provider-backed features. See [build instructions](https://github.com/devdasx/oath-wallet/blob/v4.0.3/Documentation/PublicBuild.md).

This GitHub release publishes source code. It does not submit an App Store build
or claim reproducible equivalence to an App Store binary.

## Release validation

Performed against the sanitized public source:

- Generic iOS Release build with signing disabled: passed.
- Shared diagnostics coverage: passed (490 observed catch sites).
- Diagnostics host tests: 51 executed, 1 opt-in test skipped, 0 failures.
- Wallet lifecycle host harness: 131 lifecycle checks and 37 reset checks passed.
- Public-source export scan: no unreviewed Gitleaks findings. Exact public-fixture
  exceptions are documented and protected by whole-file hashes.
- Local deployment-credential comparison: no known configuration values found in
  publishable files.

The lifecycle harness uses synthetic storage and derivation/network adapters. It
does not verify real WalletCore derivation, legacy migration, Keychain, Face ID,
live signing, or broadcasting. No simulator or physical device was launched for
this source release. These checks are not an independent security audit.
