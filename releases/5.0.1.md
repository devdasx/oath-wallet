# Oath Wallet 5.0.1 (103)

## Changes

- After wallet setup, Oath offers the applicable backup choices for that wallet. A newly created wallet can be backed up to iCloud or checked manually. Imported wallets with an existing recovery method can be offered an encrypted iCloud backup. The reminder distinguishes a queued backup from a confirmed copy.
- Bitcoin reports when a transaction has too many candidate inputs. Regression tests check signed transaction fees at the relay floor and at fractional fee rates. A send draft is cleared if its sending wallet becomes unavailable.
- WalletConnect can recover an existing proposal for the same pairing. Permission reviews handle allowances that have already been revoked.
- Transaction history handles failed Celo transactions with a recorded gas debit or refund. Balance and history refreshes handle stale index data and wallet changes more reliably on supported networks.
- Token discovery and artwork handling improve for IoTeX and Sui. Exchange rates can recover from a failed feed without discarding the last saved rates.
