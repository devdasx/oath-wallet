Oath Wallet · Product reference

A wallet with a clear identity.

Oath Wallet is a free, open-source Bitcoin and crypto wallet for iPhone and iPad. The app was previously named Aperture Wallet.

What Oath does

Oath is a self-custody wallet: you control the recovery credentials and authorize transactions on your device. It brings supported wallet imports, Bitcoin address choices, network-fee review, WalletConnect and optional encrypted iCloud backup into one app. Supported features depend on the network, wallet type and release.

Explore the features, check the supported networks, or start with the backup and recovery guide.

Publisher and team

The publisher identified in Oath’s legal and press information is STAGE AND STYLE COLLECTIVE LLC. Its published founder and CEO is Marco Valenti.

Follow the official Oath Wallet account and Marco Valenti’s public profile. The press kit provides the company information and approved brand assets.

Aperture became Oath Wallet

Oath Wallet is the new name of Aperture Wallet. The official App Store app retains the same app identifier, 6780187283. Existing references to Aperture in older reviews or screenshots describe that earlier name.

Use oathwallet.org for the website and the official App Store link below for the app. The app preserves its existing bundle, Keychain and iCloud container identifiers for compatibility.

Open source and review scope

The public source repository includes the code, license, review scope and security policy. The current source references were checked on October 30, 2026 against 4.1.14 (98), commit v4.1.14. Version 4.1.14 (98) is a public source release. No App Store Connect upload or review submission was started for this source release. See the release record for completed checks.

Public source does not establish an independent security audit or prove that a particular App Store binary matches that source. Read the security evidence and limitations, including the release-specific Silent Payments restrictions.

Product guides and corrections

Oath Editorial is the byline used for Oath’s product guides. These articles are product documentation, not independent security reviews. Updated guides identify the reviewed source release and label older screenshots. For corrections, use the support page; report sensitive vulnerabilities through the private GitHub channel.

Help and vulnerability reports

For product guidance, use the support page and practical guides. For a security issue, follow the repository’s reporting policy. That policy describes the status of its private reporting channel; do not post exploit details in a public issue while arranging a private channel.

Never send a recovery phrase, private key, passphrase, backup credential or passkey to anyone claiming to be support. Oath cannot recover missing credentials or reverse an on-chain transaction.
