# About Oath Wallet — Team, Open Source & Official Links

Oath Wallet is a free, open-source Bitcoin and crypto wallet for iPhone and iPad.



## What Oath does

Oath is a self-custody wallet: you control the recovery credentials and authorize transactions on your device. It brings supported wallet imports, Bitcoin address choices, network-fee review, WalletConnect and optional encrypted iCloud backup into one app. Supported features depend on the network, wallet type and release.

[Explore the features](/features), [check the supported networks](/networks), or start with the [backup and recovery guide](/articles/backup-restore-oath-wallet).

## Open source and review scope

The [public source repository](https://github.com/devdasx/oath-wallet) includes the code, license, review scope and security policy. The current source references were checked on November 2, 2026 against version 5.0.1 (103), tag v5.0.1-build103. App Store Connect listed iOS version 5.0.1 as Waiting for Review on 2 November 2026. The GitHub release records the source checks, host tests and unsigned iOS build.

Public source does not establish an independent security audit or prove that a particular App Store binary matches that source. [Read the security evidence and limitations](/security), including the release-specific Silent Payments restrictions.




## Product guides and corrections

Oath Editorial is the byline used for Oath’s product guides. These articles are product documentation, not independent security reviews. Updated guides identify the reviewed source release and label older screenshots. For corrections, use the support page; report sensitive vulnerabilities through the private GitHub channel.

## Help and vulnerability reports

For product guidance, use the [support page](/support) and [practical guides](/articles). For a security issue, follow the [repository’s reporting policy](https://github.com/devdasx/oath-wallet/security/policy). That policy describes the status of its private reporting channel; do not post exploit details in a public issue while arranging a private channel.

Never send a recovery phrase, private key, passphrase, backup credential or passkey to anyone claiming to be support. Oath cannot recover missing credentials or reverse an on-chain transaction.
