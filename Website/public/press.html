About Oath (boilerplate)

Oath is a self-custody Bitcoin and crypto wallet for iPhone and iPad, built on one idea: a wallet, not a marketplace. Keys are created and kept on the user’s device — Oath never holds them. People can create a new BIP39 wallet or import supported BIP39, Electrum and aezeed recovery material, restore an existing encrypted iCloud backup with its backup password, and use Taproot, SegWit, Legacy where supported by the imported material. The app is open source, with a documented security scope.
