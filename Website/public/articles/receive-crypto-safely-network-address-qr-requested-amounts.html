Receive Crypto Safely: Match the Network and Address

Use the address displayed for your selected wallet and exact asset network.

Oath Editorial · 2 min read

Screenshots reflect the app version available at the time of original publication.

In this guide

  1. Current release guidance
  2. Select the wallet and network
  3. Copy and verify
  4. Understand address types
  5. Confirm the deposit

Updated October 30, 2026 · source 4.1.14 (98)

Current release guidance

Checked against the 4.1.14 source. Build 98 uses the GitHub upload-only workflow; check the version installed on your phone. Older screenshots are illustrative and may show controls absent from this release.

Select the wallet and network

Open the intended wallet, select the asset and tap Receive. An identical ticker or familiar logo does not prove that two token deployments or chains are interchangeable. Confirm that the sender offers the same network.

Copy and verify

Use the app’s copy action or QR code. Compare the complete destination on trusted devices. For a token, verify its chain and contract or identifier. Include a memo or destination tag whenever the receiving service requires it.

Understand address types

Bitcoin formats depend on the imported material. A fresh receiving address can belong to the same wallet. Silent Payments receiving and discovery are not supported in 4.1.14; old sp1 examples are not current setup instructions.

Confirm the deposit

Check the transaction on the correct network and allow the app to refresh. A QR code or successful address copy does not prove that a transfer occurred. Never send funds to an address shown only in a help screenshot.

See the current security model, Help Center, and release verification record. Never share recovery words, private keys or backup passwords with support.
