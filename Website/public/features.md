# Oath features

Everything you need. Nothing you don’t.

## 01. Create or import a recovery phrase

New wallets use BIP39. Import supported BIP39, Electrum and aezeed phrases in their original format. Electrum and aezeed recover supported Bitcoin accounts and require manual recovery backups; they are not eligible for iCloud backup in 4.1.14.

## 02. Restore an encrypted backup

Restore an existing encrypted Oath backup using its backup password and the backup file in iCloud Drive. Keep a separate recovery-phrase backup and any extra BIP-39 passphrase.

## 03. 57 app localizations

Oath is available in 57 app localizations, with right-to-left layouts, local number formats and BIP39 word lists.

## 04. Open source, with a documented review scope

The full source code is public on GitHub at https://github.com/devdasx/oath-wallet. The published release includes its security model, verification record and reporting policy. Public source is available for review; it does not establish an independent audit or a verified match to the App Store binary.

## 05. Bitcoin address options

Compatible Bitcoin wallets support Taproot, Native SegWit, nested SegWit and Legacy, depending on the imported material. Capabilities vary by network. Oath 4.1.14 does not support Silent Payments receiving or discovery; see the Silent Payments guide before relying on that feature.

## 06. EVM Access

A tool that shows discovered token approvals (web3 permissions) on supported EVM networks and lets the user submit supported revocation transactions. Revoking is an on-chain transaction with a network fee shown before confirming.

## 07. Your display currency

Choose from the app’s supported display currencies. Values are estimates based on available exchange-rate data.

## 08. Available market prices

See available price quotes for supported assets. Quotes can be delayed or unavailable; displayed fiat values are estimates.
