# Polygon wallet: send and receive POL

Receive, send and manage assets on Polygon with Oath for iPhone and iPad. Keep your network, address and fee details in view.

## Receive Polygon

1. Open Oath, select your wallet and choose Polygon in Receive.
2. Copy the receiving address or show its QR code. Confirm the exact network with the sender.
3. Use Polygon PoS. POL pays the network fee; Polygon zkEVM is a different chain.
4. After the sender broadcasts the transfer, follow its status in Oath. Network confirmation can take time.

## Send POL

1. Open Send and select the asset on Polygon. Paste the recipient’s address or scan their QR.
2. Keep POL available for network fees. For tokens, check the contract and amount, then review the destination and estimated fee in Oath.
3. Enter the amount and any required memo or tag. Compare the complete destination with the recipient’s instructions.
4. Review the asset, network, amount and fee, then confirm in Oath. Follow the transaction status after broadcast.

## dApp connections

Connect to compatible Polygon dApps through WalletConnect. The website must request a network and signing method supported by Oath. Review every connection and signing request in the app.

1. Open a trusted dApp and choose Oath if it is listed, or choose WalletConnect.
2. On desktop, scan the connection QR with Oath. On iPhone or iPad, use a compatible app link or the connection option offered by the dApp.
3. Review the website, selected wallet, Polygon network and requested permissions before approving.
4. Review each signing request separately. Disconnect the session from Oath when you are finished.

## Questions

### How do I receive Polygon in Oath?

Open Oath, select your wallet and choose Polygon in Receive. Copy the receiving address or show its QR code. Confirm the exact network with the sender. Use Polygon PoS. POL pays the network fee; Polygon zkEVM is a different chain.

### What pays the Polygon transaction fee?

POL is the native fee asset for this network account. Keep POL available for network fees. For tokens, check the contract and amount, then review the destination and estimated fee in Oath.

### Can I connect Polygon dApps?

Connect to compatible Polygon dApps through WalletConnect. The website must request a network and signing method supported by Oath. Review every connection and signing request in the app.

### Can I send to the same address on another network?

Only send using the network the recipient explicitly supports. A matching address or ticker does not bridge assets or make different chains interchangeable.

Features depend on the app version, network, wallet type and the service you connect to. Check the available actions in your installed app before transferring.
