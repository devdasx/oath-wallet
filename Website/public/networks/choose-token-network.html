Oath Wallet · Transfer preparation

Which network should I use?

Compare USDT and USDC entries in Oath’s released catalog. Match the sender’s network, exact token identity and fee asset before transferring.

Get Oath for iPhone
  1. Start with the sender. Open its available withdrawal networks for the exact token. If your intended network is not offered, do not use another network’s address as a substitute.
  2. Match the receiving account. In Oath, open Receive on the same network. Compare the exact contract or mint on the token page below and with the issuer’s current information.
  3. Plan for a later send. Check the native fee asset and any account requirements. Fees alone do not determine compatibility.
  4. Check before confirming. Compare the full receiving address, network and token at the sender. A small first transfer can help verify the route.

These are entries from the released catalog’s USDT and USDC asset groups. Other bridged tokens may be listed separately. No selection here moves funds, bridges tokens, connects a wallet or establishes what an exchange supports.

If the network or token does not match

Stop before sending. An identical EVM address does not join balances across networks. Importing the same keys does not bridge tokens. A matching symbol does not establish that two contracts are the same asset.

If a transfer has already been broadcast, keep its public transaction ID and check the exact network, destination and token in the explorer. A completed exchange withdrawal request is not necessarily a confirmed on-chain transfer. Contact the receiving service about its recovery scope when needed.
