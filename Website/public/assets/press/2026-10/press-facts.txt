LONG DESCRIPTION
Oath Wallet is a self-custody Bitcoin and crypto wallet for iPhone and iPad, developed by STAGE AND STYLE COLLECTIVE LLC. It brings supported assets, balances and transaction activity into one native app, alongside wallet connections to supported dApps. Oath is built around ownership: users manage their wallet and authorize their transactions. Its public GitHub repository and security documentation explain the product’s source, release process and security scope. Oath is free to download; blockchain network fees and any applicable service fees are separate. Features and connection methods vary by network and app version. Visit oathwallet.org for current product information.
