## Short introduction

Oath is a self-custody Bitcoin and crypto wallet for iPhone and iPad. It brings supported coins and tokens together in a native interface, with simple sending and receiving, WalletConnect for dApps, and public source code on GitHub.

## Longer introduction

Oath Wallet is a self-custody Bitcoin and crypto wallet built natively for iPhone and iPad. It brings supported assets, balances, and transaction activity into one place, with clear send and receive flows and WalletConnect for connecting to dApps. Wallet tools include watch-only addresses, multiple Bitcoin address formats, physical-entropy wallet creation, and optional encrypted iCloud backups restored with the matching passkey. Oath publishes its source code on GitHub, alongside documentation of its security scope and release process. The app is free to download; blockchain network fees apply to transactions. Oath Wallet is developed by STAGE AND STYLE COLLECTIVE LLC and was previously known as Aperture.
